# Совместимость Claude Code и Codex

Проект работает в двух средах:

- Claude Code читает `CLAUDE.md` и skills из `.claude/skills/`.
- Codex читает `AGENTS.md` и skills из `.agents/skills/`.

## Единый источник данных

Обе среды используют без копирования `SOUL.md`, `USER.md`, `MEMORY.md`, `memory/`, `knowledge/`, `content/` и `instructions/`.

## Правила синхронизации

1. Меняя общую логику, обновляй `CLAUDE.md` и `AGENTS.md` в одной задаче.
2. Устанавливай каждый skill в обе папки.
3. Сохраняй одинаковыми `name`, `description` и смысл тела парных skills.
4. Сохраняй нативный frontmatter: Claude-копия может содержать дополнительные поля, Codex-копия содержит только `name` и `description`.
5. Не записывай секреты в инструкции, память или URL веб-инструментов.
6. После установки нового skill начни новую сессию в обеих средах.

## Передача работы

В конце содержательной сессии допиши `memory/ГГГГ-ММ-ДД.md`: что сделано, что осталось и какие решения приняты. Следующий агент читает последний дневник и продолжает работу.
