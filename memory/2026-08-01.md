## Аудит совместной работы Codex и Claude Code

### Что проверили
- Общие файлы `SOUL.md`, `USER.md`, `MEMORY.md`, `memory/`, `knowledge/`, `content/` и `instructions/` используются обеими средами напрямую, без копий.
- Для трёх установленных skills есть парные версии в `.agents/skills/` и `.claude/skills/`.
- Таблицы skills в `AGENTS.md` и `CLAUDE.md` совпадают; различия самих файлов связаны в основном с нативными командами двух сред.
- Все основные Markdown-файлы имеют корректную кодировку UTF-8.

### Риски
- Папка не является Git-репозиторием: нет локальной истории и простого отката после случайной перезаписи.
- Нельзя одновременно давать Codex и Claude задачи, которые меняют один и тот же файл: победит последнее сохранение.
- Тела парных skills `unpacking` и `research-idea` отличаются не только frontmatter, поэтому при будущих обновлениях возможен рассинхрон поведения.
- Installer использует Bash-команды, хотя рабочая среда Windows может запускать PowerShell; это нужно учитывать при установке.
- Файл `instructions/dual-agent-rules.md` существует, но прямой ссылки на него из `AGENTS.md` и `CLAUDE.md` нет.

### Вывод
- Работать попеременно в Codex и Claude Code с одной папкой можно.
- Общие данные копировать не нужно.
- Skills пока приходится держать в двух адаптированных копиях и синхронно обновлять.
- Одновременное редактирование одного файла двумя агентами небезопасно.
